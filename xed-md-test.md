# 1. Hauptüberschrift (H1)
Dies ist ein normaler Fließtext-Absatz. Sie können Text **fett formatieren** oder *kursiv darstellen*. Wenn Sie Code im Text erwähnen möchten, nutzen Sie `formatierten Code`.

## 2. Unterüberschrift (H2)
Hier sehen Sie, wie Listen und Aufzählungen aufgebaut sind.

### 3. Unter-Unterüberschrift (H3)
*   Erster Punkt einer ungeordneten Liste
*   Zweiter Punkt
    *   Eingerückter Unterpunkt
*   Dritter Punkt

Für nummerierte Abläufe nutzen Sie Zahlen:
1.  Erster Schritt
2.  Zweiter Schritt
3.  Dritter Schritt

## 5. Tabellen und Code-Blöcke

| Funktion | Shortcut / Syntax | Beschreibung |
| :--- | :--- | :--- |
| Fett | `**Text**` | Macht Text fett |
| Kursiv | `*Text*` | Macht Text kursiv |
| Code | \`Code\` | Inline-Codecode |

Mehrzeiligen Programmiercode blockweise darstellen (hier am Beispiel von Python):

```python
def hallo_welt():
    print("Hallo Linux Mint User!")

hallo_welt()
```

Verwenden Sie am Ende des Dokuments bei Bedarf eine Trennlinie wie oben zu sehen (`---`).
